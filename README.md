# Valm.Teh_darbi — Workspace README

This repository contains several small projects. The one we updated here is the library (bibliotēka) demo located at:

	Programas_Izstrādes_Process/BIBLOTEKAS_SIST

The library demo includes:

- A static frontend: `bibloteka.html`, `func/bibloteka.js`, `style/bibloteka.css`.
- A small Python Flask API under `database/` that persists to JSON files (`data.json` and `cache/users.json`).
- A helper module `EIKT_DATUBASE.py` centralizing data reads/writes.

See `RUNNING.md` for step-by-step instructions to run the API and the frontend locally.
